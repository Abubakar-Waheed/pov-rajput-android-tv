The player identifies the debrid service that resolved the current stream. Logos are bundled locally; displaying them makes no network request.

- Real-Debrid: [official site icon](https://fcdn.real-debrid.com/0840/favicons/android-chrome-192x192.png).
- AllDebrid: [official site wordmark](https://cdn.alldebrid.com/lib/images/default/logo_alldebrid.png).
- Premiumize: [official site icon](https://www.premiumize.me/apple-touch-icon.png).
