# After the first Rajpoot release

These requests are deliberately deferred until the initial branded Offcloud release is published.

## Transparent subtitle background

Add a player subtitle-style setting that permits a fully transparent background while preserving readable foreground/outline choices. Keep the choice on-device, expose it through TV-friendly settings, and verify embedded subtitles and subtitle Off behavior. Confirm interaction with Android caption preferences before choosing the default.

## Wetrakr integration

Investigate https://wetrakr.com/ for an official integration/API, authentication method, supported media identifiers, playback/progress events, and service terms. Do not request or store credentials until an actual supported integration is designed. Define how it coexists with the existing Trakt integration and local history. If no public API is offered, document the limitation rather than scraping private account pages or claiming support.
