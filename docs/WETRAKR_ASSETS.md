# WeTrakr artwork

The navigation logo uses the official transparent WeTrakr full logo from [WeTrakr Logos & colors](https://api.wetrakr.com/#/brand).

Source: https://api.wetrakr.com/assets/brand/v5/wetrakr-logo-blue.svg

The original path geometry and gradient are represented as Android vector drawables. The light-background variant uses WeTrakr Night (#13161d) for the lettering. WeTrakr name and artwork belong to their respective owners. Library data is attributed to WeTrakr wherever displayed; this app is not endorsed by WeTrakr.
